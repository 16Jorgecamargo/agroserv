Da ideia à implementação.

Duas entregas. A primeira desenhou a experiência; a segunda construiu o sistema que a sustenta, sem reescrever as telas.

Primeira entrega

Uma experiência construída para conectar.

Desenvolvimento da interface do AgroServ, com navegação entre funcionalidades, fluxos de utilização e integração com uma API simulada.
