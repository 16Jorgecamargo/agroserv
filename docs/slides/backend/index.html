06 · Contrato

Um envelope para tudo.

Sucesso
200 GET /services?q=pulverizacao { "success": true, "data": { "data": [ { "title": "Pulverização…" } ], "meta": { "page": 1, "total": 3, … } } }
Erro de validação
422 POST /auth/register { "success": false, "error": { "code": "validation_error", "message": "Revise os campos destacados.", "fields": { "email": "Informe um e-mail válido." } } }

O httpAdapter desembrulha o envelope. Erro vira ApiError e o formulário marca o campo.

09 · Segurança

Quem confere é o servidor.

✓Senhas guardadas com bcrypt
✓Sessão JWT de 7 dias, com o papel
✓5 senhas erradas em 15 min → 429
✓Link de recuperação: uso único, 60 min
✓No máximo 3 e-mails de recuperação por hora
✓Documento de verificação: link de 10 min
✓Conta suspensa não entra
✓Helmet e CORS por origem
✓Limite de 300 requisições por minuto
✓Campos fora do DTO são descartados

As mensagens de erro são as mesmas do mock: a tela mostra o mesmo texto nos dois modos.

13 · Como rodar

Na sua máquina, em dois terminais.

API · pasta backend
$ cd backend
$ pnpm install
$ cp .env.example .env
$ pnpm start:dev
Front-end · raiz
$ cp .env.example .env
$ npm run dev

No .env, troque para VITE_API_MODE=http.
